# 🎮 PokéStats — Dashboard de Estatísticas Pokémon

## 📌 Sobre o projeto

O **PokéStats** é um dashboard interativo desenvolvido como projeto acadêmico, com o objetivo de apresentar e explorar dados relacionados ao universo Pokémon.

A proposta é visualizar informações sobre as diferentes gerações de Pokémon, os Pokémon mais utilizados no cenário competitivo e dados relacionados à popularidade de cada geração, por meio de gráficos e recursos interativos.

## 🎯 Objetivos

- Apresentar informações sobre as gerações de Pokémon.
- Identificar os Pokémon mais utilizados no cenário competitivo.
- Comparar estatísticas entre diferentes gerações e períodos.
- Desenvolver gráficos interativos para facilitar a visualização dos dados.
- Integrar APIs para obter informações sobre Pokémon.
- Implementar funcionalidades de cadastro, consulta, edição e exclusão de dados (CRUD).

- Visualização de estatísticas por geração.
